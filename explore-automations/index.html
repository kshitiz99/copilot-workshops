Duration: 25 minutes

Find test gaps. Add meaningful coverage.

So what A passing test suite does not prove every important behaviour. Use the codebase map to find missing or weak tests, then turn one verified gap into a regression test.
1Meet the Test Gap Audit skill5 min

Open Test Gap Audit on Awesome Copilot ↗. This skill compares code paths with what existing tests actually assert. It stays read-only until you explicitly ask it to add tests.

1 Map the behaviour

Inspect source, existing tests and repository test conventions.

2 Rank the gaps

Prioritise by impact, with evidence and concrete test scenarios.

3 Prove the behaviour

Prefer meaningful assertions over a higher coverage percentage alone.

2Run a read-only audit of Tailspin Toys8 min

Read the report before acting. A file without a directly matching test may still be covered indirectly. If the audit cannot finish in this session, use its list of areas not deeply inspected for a follow-up pass.

3Generate a local HTML audit report2 min

Once the audit is complete, ask Copilot to turn the finalised findings into a simple local HTML page. Save the report outside the repository to keep the audited files unchanged, then open it in your browser.

Keep the priorities, source evidence and checks run or skipped visible in the report. Generating the report does not authorise implementing the suggested fixes or tests.

4Create GitHub issues for the P1 gaps10 min

The recording asks for two issues because that audit found two P1 gaps. Your audit may rank gaps differently, so create one issue per P1 gap in your report.

Checkpoint Raise your GitHub issues
  • Create one GitHub issue in your own tailspin-toys repository for each P1 gap from your audit.
  • Include the finding, source evidence and proposed tests in each issue.
  • Open the repository's Issues tab and confirm the issues are published, not just drafted in chat.
Duration: 10 minutes

From unfamiliar code to meaningful tests

The takeaway Understand first. Audit with evidence. Add tests that prove behaviour. Copilot helps investigate and implement. You review the evidence, choose the gap and check the results.

The loop you can reuse

Run → Map → Audit → Choose → Test → Verify

Repeat for the next behaviour or area that needs deeper inspection.

Before you finish Show the evidence, not just the output
  • Show the running app and explain one path through it.
  • Trace a codebase document's finding back to its source.
  • Explain one confirmed test gap and the regression a proposed or added test would catch.
  • Show the focused test results, or clearly state what could not run and why.

No measured before-and-after coverage? Do not claim a percentage improvement. Describe the behaviour now protected and any work still outstanding.
